# Lab: Unified Release Harness

Chinese: [lab.zh.md](lab.zh.md)

Create a runner for 50 normal, 20 edge, and 30 adversarial cases. Score retrieval recall/MRR, grounded evidence, task success, tool correctness, policy denials, unsafe actions, loop length, latency, and estimated cost. Calibrate ten cases with two human reviewers. Generate a machine-readable report and fail the command when gates fail.
