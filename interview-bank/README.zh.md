# XingAI AI 面试题库

English: [README.md](README.md)

题目用于引导，不是背诵脚本。根据岗位级别评估证据、推理、纠错行为与沟通能力。

## 初学者

1. 用具体案例解释训练与推理。
2. 实现 Cosine Similarity，并测试零向量。
3. 解释 Precision、Recall，以及 Accuracy 会误导的场景。
4. 什么是 Embedding？距离不能证明什么？
5. 介绍一个项目、它的 Baseline 以及你发现的一个失败。

## AI 工程师

1. 设计包含超时、重试、校验与评估的类型化 LLM Endpoint。
2. 调试“文档相关但答案无依据”的 RAG 系统。
3. 比较 RAG、长上下文、搜索、Fine-tuning 与确定性查询。
4. 设计工具 Schema，并指出它的授权边界。
5. 除任务完成率外，如何评估 Agent？

## Senior 与 Staff

1. 设计可在重启后恢复且避免重复写入的 Durable Agent Workflow。
2. 调查模型变更后的不安全操作率回归。
3. 为 AI 服务定义 SLO、Canary Gate、可观测性与回滚。
4. 对通过检索文档和工具传播的间接 Prompt Injection 做威胁建模。
5. 解释何时多 Agent 不如单一工作流。

## 架构师

1. 绘制领域 API、MCP Gateway、Orchestrator、Policy Engine 与 Event Bus 的边界。
2. 设计包含删除、ACL、Provenance 与审计的多租户 RAG 平台。
3. 分离决策计算、传输、解释、审批和执行。
4. 规划从 AI Demo 到受治理决策系统的迁移。
5. 解决产品速度与安全控制要求之间的分歧。

## CTO

1. 在资金有限、收益不确定的情况下选择并排序十个 AI 机会。
2. 定义 Build/Buy/Partner 标准和厂商退出策略。
3. 设计跨平台、产品、安全、风险和数据团队的 AI 运营模型。
4. 分别说明重大 AI 事故发生后一小时、第一周和下一季度的行动。
5. 向董事会解释 AI 投资、剩余风险与终止标准。

## 统一追问

每个答案都追问：最重要的假设是什么？拒绝了什么 Baseline？如何度量成功？哪个部分最先失败？谁负责结果？规模扩大十倍会怎样？什么条件会让你停止？

## 评分锚点

较弱答案只罗列工具；合格答案定义需求与可运行 Baseline；优秀答案量化权衡、故障和证据；卓越答案能适配受众深度、主动呈现不确定性、建立责任归属，并在不回避问题的前提下改善问题定义。
