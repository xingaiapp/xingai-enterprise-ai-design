## Capstone project

> **Claims Copilot Agent** — summarize Claim, detect risk, query Policy, recommend next action, add Claim Note only after human approval.

Illustrative TPA / claims-operations context. Not confidential client SOPs or production schemas.

## Audience

- Engineers who can call an LLM API but need enterprise Agent skills for interviews and delivery
- Architects joining claims / insurance tech programs (Azure, .NET, Entra ID preferred; SQLite fine for local labs)

## How to study

1. Finish Course 03 (or equivalent Agent basics) before Chapter 3 if Tool Calling is new.
2. Skim [Claim Business](../claim-business/README.md) Levels 1–2 for Adjuster / Claim vocabulary.
3. Complete Chapters 1–2 before building tools.
4. Build the lab increments (Newbie → Expert) with a private portfolio repo.
5. Pass the acceptance checklist (10 defense questions) before calling the project “resume-ready.”
